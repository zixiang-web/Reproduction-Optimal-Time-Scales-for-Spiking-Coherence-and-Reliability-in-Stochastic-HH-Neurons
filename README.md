# Reproduction-Optimal-Time-Scales-for-Spiking-Coherence-and-Reliability-in-Stochastic-HH-Neurons
This repository provides a complete Python reproduction of the paper: Optimal time scales of input fluctuations for spiking coherence and reliability in stochastic Hodgkin–Huxley neurons, DOI: 10.1016/j.physa.2016.10.087. We reproduce all simulation experiments and data figures in the paper.
